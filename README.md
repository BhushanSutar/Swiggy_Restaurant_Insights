# Swiggy Restaurant Insights – India

**Interactive Analysis of Swiggy Restaurants Across India!**

---

## 📌 Overview
This project delivers deep **retail analytics and visual storytelling** on restaurants listed on Swiggy across India. Using real-world data analysis and a sophisticated **Power BI dashboard**, it uncovers trends around pricing, ratings, cuisine distribution, and regional patterns—equipping stakeholders with insights that can drive strategic decisions.

---

## 📂 Project Assets
| File | Description |
|------|-------------|
| `swiggy_report_india.pbix` | Power BI file containing the comprehensive dashboard and report |
| `Swiggy_Report_.pdf` | PDF version of the dashboard—great for quick viewing or sharing |

---

## 📊 Key Insights
- **Cuisines**: Identify the most prevalent cuisines across Indian cities and how they vary regionally.  
- **Pricing & Ratings**: Spot correlations between restaurant cost and customer ratings, uncover affordable gems, and flag potential outliers.  
- **Regional Trends**: Discover cities with the highest restaurant listings, top performers, and those with noteworthy cost or rating dynamics.  

---

## 🛠️ Technologies Used
- **Power BI** for interactive dashboards, visualisations, and insights.  
- (Optional) **Python / SQL / Excel** used during data preparation or analysis—refer to dashboard contents for details.

## 🚀 How to View the Dashboard
1. **Download** the project files locally.  
2. Open `swiggy_report_india.pbix` with **Power BI Desktop** to interact with the live dashboard.  
3. Or just view the `Swiggy_Report_.pdf` for a static snapshot of the key findings.
